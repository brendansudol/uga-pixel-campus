# UGA Pixel Campus

A looping pixel-art diorama of the University of Georgia's North Campus, with sound. The whole scene is drawn in code on a 240×240 canvas, and every sound is synthesized live with the Web Audio API. There are no image or audio files.

**Live:** https://brendansudol.github.io/uga-pixel-campus/

## What happens in the 26-second loop

- A freshman walks up to the Arch, remembers the rule, and goes around it. Later a graduate walks right through.
- Uga naps by his doghouse until a squirrel runs past.
- An alarm clock goes off in a dorm room and gets snoozed.
- The Chapel Bell rings on the roof, next to a tailgate grill.
- A Redcoat trumpeter plays "Glory, Glory" while G-E-O-R-G-I-A floats up, one letter per note. The librarian shushes him.
- A plane tows a "HOW 'BOUT THEM DAWGS" banner overhead.

Click the scene to turn on sound. Click again (or press Space) to pause.

## Run locally

It's a single HTML file: open `index.html` in a browser.
